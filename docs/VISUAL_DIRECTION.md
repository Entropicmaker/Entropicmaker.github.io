# Linzii的地理小站 · 视觉构思

实现阶段：「坐标档案」已接入正式博客，当前正式版本为 v006，修复入场淡出回闪并移除跳过及重播按钮；六份概念稿快照保留。发布记录见 [VISUAL_VERSIONS.md](VISUAL_VERSIONS.md)。

概念稿版本：v005；正式站版本：v006。用户要求后续每一版均可恢复；版本快照和恢复流程见 [VISUAL_VERSIONS.md](VISUAL_VERSIONS.md)。修改前先核对并保存当前版本，完成后另存新编号，不覆盖已有快照。

## 已确认的方向

- 重点借鉴平面设计与动效，而不是直接复刻游戏人物、标志或三维场景。
- 保留原博客的灰绿、深青、苔绿、暖棕及自然、研究、个人记录的气质。
- 允许局部反色和少量新强调色。配色关系与整体气质延续原站，不要求每个模块都只用原来的颜色。
- 首页主标题使用“Linzii的地理小站”；现有站点署名“选择性失忆”暂时保留。

## 参考视频与设计解读

参考分析覆盖前两支视频从片头到片尾的画面序列，约每两秒抽取一帧；入场视频另外提取约四分之一秒间隔的片头序列，并核对全片的主要切换。这个方法适合核对构图、色彩和动作顺序，具体运动曲线仍需在实现阶段逐项调整。

1. [《明日方舟》特别映像：莱茵生命·访问](https://www.bilibili.com/video/BV1rr4y1b7sz/)，5分19秒。
   - 浅底、细线、极大的留白，紧凑的英文标题和技术标注，信息与图像分层出现。
   - 部门索引、档案抽取、连接线和编号让界面具有组织关系，而不是单纯增加装饰。
   - 后段转入黑底档案，反色同时承担叙事切换与重点强调。
   - 博客借鉴：分类索引、文章编号、项目档案、线条展开与内容揭示。
2. [《明日方舟×女神异闻录3 Reload》月行水上宣传PV](https://www.bilibili.com/video/BV1zCtA6mEay/)，3分16秒。
   - 超大字与极小标注的尺度反差；大字可以裁切、错位、穿插图像，文字本身参与构图。
   - 圆盘、斜切平面、单色剪影、实心字与描边字、黑白与高饱和色的切换。
   - 中段角色介绍与后段服装展示有不同的平面布局；共同点是明确的主视觉、辅助色和快速图文转场。
   - 博客借鉴：首页标题、特色文章和项目封面。主体转译为深青与苔绿，局部使用暖棕或明亮薄荷色。
3. [主界面入场动画](https://www.bilibili.com/video/BV1b2ti6REdf/)，3分50秒。
   - 开头约五秒完成暗场标题、色块扫入、超大字与剪影切换、圆形遮罩扩展和界面落位。
   - 转场时的小标题保持位置，后方构图在运动；这让强烈变化仍有一个稳定的视觉锚点。
   - 后续主界面在拼贴与圆盘、大字组成的几何构图之间切换。
   - 博客借鉴：用站名作为稳定锚点，经纬网、观测圆盘和测量线替代人物剪影。

## 推荐构思：坐标档案

用“坐标档案”的层级作为全站基础，保持连续的空间与清楚的视觉中心。文章阅读页保持平静，字体、颜色、行距与首页使用同一套系统。

### 第一版自我审查与修正

第一版对“平面化”的处理过于生硬：主图的矩形外框、分类的四等分边框、整块深色底与反复出现的硬切边界，让内容像独立组件拼装；入场的暖棕长条缺乏与首页的关联。细线和留白已经存在，但主次、材质层次与空间连续性没有建立好。

修正后的优先级：

- 不直接用长方体、正方体、宽直条与实心矩形作为视觉装饰。
- 主视觉取消矩形边框，使用有曲面层次的观测环与经纬曲线；标注轻贴于物件周围。
- 分类入口取消等分方框，以小圆点、文字颜色与留白表示选中关系。
- 反色集中于圆形主视觉或小面积文字，不把文章整块涂深。
- 入场与首页共用同一个观测对象；沿曲线展开、聚焦与揭示，而不是让无关联的图形依次划过。
- 入场保留参考中的右下向左上反色：以轻弧形边界扫过背景、站名、大字与观测环，在同一位置同步切换深浅配色。
- 暖棕只作为小面积的定位点与短弧，不作抢眼的宽长条。

这里借鉴的是莱茵生命的组织与层次。它原片仍有矩形档案，但那些物件边界轻、透明度和前后关系明确；网站中保留正常的内容布局，不把边框或几何方块当作主要装饰。

首页顺序：站名与图形主视觉 → 四个内容坐标 → 精选文章与最近记录 → 项目档案 → 标签索引。

- 首页：左侧标题，右侧开放的观测图形。以曲面线条、微弱的明暗层次、留白与少量标注建立视觉中心。
- 分类：四个有编号的文字入口，用小圆点与文字颜色表示选择。分类名保持直观中文，英文编号仅作辅助。
- 文章列表：以横向档案行、日期和标题为主，减少重复的大圆角盒子。
- 特色文章：通过字号、间距与短标题强调主次，反色仅作局部重点；普通文章保持浅色纸面。
- 项目：可加入遥感图、实际截图或数据图的局部切片，与文字形成错层；不把无意义的系统状态当作内容。
- 阅读页：正文约700–760px宽，建议中文17–18px、行高1.85左右。动效集中于进入页面、目录与阅读进度。

### 颜色关系

| 用途 | 色值 | 新设计中的用途 |
| --- | --- | --- |
| 灰绿底 | `#f1f4f1` | 大面积纸面、页面留白 |
| 深色文字 | `#183034` | 标题、局部反色底 |
| 深森林绿 | `#173b33` | 入场暗场、地理剪影与深浅对比 |
| 深青 | `#174653` | 主操作、经纬轨迹与坐标定位 |
| 苔绿 | `#5b7f65` | 地理主色、图形和分类线 |
| 浅绿 | `#e3ece1` | 图形底与次级内容 |
| 暖棕 | `#b9865e` | 测量点、标签和极少量强调 |

额外颜色由具体图片或项目主题决定，每个模块选择一个主要强调色。反色通过深浅色组合实现，避免对正文、图片和整个页面统一套用颜色反转。

P3R 的参考重点是颜色的角色与主题一致性。[开发者访谈](https://www.famitsu.com/news/202311/29325647.html)将蓝色、水面与心境联系起来；[社区复现案例](https://adrian-kowalik.com/projects/persona-3-reload-ui-recreation)也展示了白色留白、黑色选中项和小面积红色强调如何参与同一构图。联动 PV 中的角色配色有具体对象，不能转译为每种颜色都同等铺满博客的循环。

当前沿用 v001 的绿系配色：深森林绿提供近景暗场，苔绿建立地理主题，浅绿提供留白。原站深青在地理计算段沿经纬曲线推进到定位点，暖棕点亮定位点和短弧，暗场使用原站的暖棕亮阶 `#d3a47d`。最后落回首页的灰绿或当前深色主题。钴蓝、青绿和鸢尾紫的旧方案保存在 v000。

### 动效编排

| 操作 | 建议时长 | 动作 |
| --- | --- | --- |
| 首页首次入场 | 约2.8秒 | “Linzii的”先进入、森林绿近景 → 苔绿剪影 → 浅绿转场时揭示“地理小站”并转为描边字 → 深青轨迹连接定位点 → 当前首页底色与图形落位 |
| 分类切换 | 约650毫秒 | 旧内容短暂退场 → 圆环微扩与转向 → 分类大字浮现 → 新标题分组落位 → 编号与定位点归位 |
| 文章进入 | 约350–450毫秒 | 标题与正文分层揭示，之后停止装饰运动 |
| 链接或入口悬停 | 约140–180毫秒 | 细线伸展或局部反色 |

正式站入场只在一次会话首次进入首页时播放；v006 按用户要求移除跳过和重播按钮，保留键盘和滚动中断。返回首页不重复播放，减少动态效果偏好下直接显示内容。

右下向左上的弧面反色保留在暗场到苔绿、苔绿到浅绿和最终回到主页的三个节点，分别约392、336、392毫秒。v002 撤去 v001 的实心蓝色椭圆，改为沿定位点所在纬向曲线推进的深青细线，接近定位点时由暖棕短弧接续。v004 左上英文约34毫秒开始揭示；“Linzii的”在约98毫秒开始、658毫秒落稳；“地理小站”延后到苔绿转浅绿期间的约952毫秒开始、1.512秒落稳。两段分别用560毫秒揭示，完整站名保持到约2秒，再轻抬退出。继续保留 v003 对父层重复淡入及站名轻微旋转的移除。

最后读取首页当前的真实背景、文字与明暗主题，扫入一致的底色。浅色主页落回灰绿，深色主页落回深青黑；在揭示内容前，观测环已对齐首页位置、大小和线条浓度，额外转轴角度与漂移归零，使颜色和图形一起衔接。区域反色只复用两层图形。

横向整片覆盖的做法经复审仍像滑块，已停用。本轮再次按约0.25秒间隔核对 P3 联动 PV 的75.5–83.5秒片段：角色展示里圆盘、人物与大字分别缩放、转动，并在拉远后收束为新构图。这种关系转译到博客的实际图形与文字上。

内容坐标切换先让旧标题、编号与摘要用约105毫秒退场，再让新标题按词组轻斜着落位。观测环微扩约13%，主体转向约12度，外环反向错拍约16度；背景分类大字短暂出现，编号和暖棕定位点随之归位。全段约650毫秒，不使用实心覆盖板；连续点选会取消旧动作，状态保存回写也不会提前终止正在播放的动画。

### 已加入的入场构图动作

- **近景、剪影与留白**：开场观测对象在右侧放大裁切，苔绿反色时形成深森林绿剪影，再拉远为浅绿底上的经纬曲线。缩放以当前设备的主页图形大小为终点，避免手机结尾先缩小再反向放大。
- **连续运动**：用连续速度的曲线连接各段姿态，消除每段都重新起停的机械感。球体加入轻微漂移与转轴变化，外环另有反向转动和相位偏移；这些相对运动在主页揭示前平顺归零。
- **站名分拍进入**：英文使用克制的字距收拢与上移揭示；“Linzii的”先慢慢出现，“地理小站”在苔绿转浅绿时再出现。两层反色画面的文字动画保持同步，完整站名在约1.51秒落稳。
- **大字与圆环穿插**：坐标档案和图形随笔使用 FIELD / JOURNAL，入场顶部英文为 GEOGRAPHY / COMPUTING / EVERYDAY；研究终端保留 GEO / ARCHIVE。采用 Barlow Condensed 窄体，以小一号、疏字距的前缀配一个主词，统一左侧基线；撤去句点、频繁换词、整体倾斜和逐段缩小。主词随浅绿转场从实心转为细描边，保持到退出；前缀保持实心。经纬曲线和轨道继续按空间深度分别绘制在字后与字前。
- **外环错拍转动**：主体球体转动时，外侧测量环反向轻转，暖棕定位点延后约80毫秒跟随；深青轨迹沿曲线推进，暖棕短弧在到达定位点时接续。最后恢复首页观测环的姿态与线条浓度。

先前建议的“地理标注落位”尚未加入。当前入场约2.8秒，可在设计调节中选择2.2–4.4秒；继续保留右下向左上的区域反色与明暗主题衔接。

### v003 动效与排版复审

重新查看莱茵生命片头0–32秒、联动PV64–96秒及入场参考0–4秒的已保存画面序列，并复核 P3R [美术负责人访谈](https://www.famitsu.com/news/202311/29325647.html)和[社区菜单复现分析](https://adrian-kowalik.com/projects/persona-3-reload-ui-recreation)。访谈明确区分 P3R 的水中浮游与 P5 的弹跳速度感，同时强调菜单响应；社区案例讨论背景、主体、导航与装饰文字的独立层级。以下为针对本博客的设计判断，不是原作者给出的网页规范。

- v002 的 Arial 粗体、负字距和两个相同分量的大词堆叠，形成了过重的文字团块，与细线地球争夺注意力。v003 用窄体、32%字号的前缀与单个主词建立主次，并给文字与站名共同的左侧对齐线。
- 2–3秒内从 FIELD / NOTES 切到 GEO / GRAPHY、再到 GEO / CODE，最后切回原词；同时位置、缩放、倾斜都在变化，增加了无助于识别博客的阅读负担。v003 保持词义和构图，运动关系集中于地球缩放、反色扫入与主词实心转描边。
- v002 左上文字同时受父层淡入、子层淡入、上移与旋转控制，达到完整可读状态偏晚。v003 站名在开头半秒完成，随后留出阅读时间；总时长由3.2秒压到2.8秒，保留后半段地球减速落位和448毫秒的主页揭示。

字体优先从 Google Fonts 加载 Barlow Condensed 400/500，系统后备为 Avenir Next Condensed、Arial Narrow、sans-serif；动画结构与内容不依赖字体请求完成。手机按词长设定主词字号及更短的入场位移，避免 ARCHIVE / JOURNAL 靠近右边界。

### v004 站名节奏调整

在 v003 排版和2.8秒总时长上单独放缓中文站名，将“Linzii的”和“地理小站”拆成前后两拍。后半句在动画34%处开始；第二种苔绿向第三种浅绿的反色发生在32%–44%，因此后半句的揭示与此段转色重合。两个中文片段的揭示时间均从336毫秒增加至560毫秒，缓动减少起步时的猛冲。v003 的快速站名版本已保存，可独立恢复。

### v005 恢复预览中的英文

用户要求恢复提出站名分拍需求前看到的英文。核对当时手机播放画面，该预览为图形随笔，使用 FIELD / JOURNAL 及 GEOGRAPHY / COMPUTING / EVERYDAY；随后刷新回坐标档案默认预览，显示了另一组英文。此次将这两处入场文案接回用户选定的坐标档案，两层反色同步更新，保留 v004 的站名分拍时间及 v003 的窄体排版。

## 三种概念稿的用途

- **坐标档案**：建议作为基础；保留博客的亲切感，强化信息层级。
- **研究终端**：更克制，适合研究与项目内容；索引、标注、档案的组织关系更突出。
- **图形随笔**：更有视觉节奏，适合首页和精选栏目；圆形主视觉、淡化的大字与局部反色建立错层。

目前概念稿可试明暗配色、分类切换、局部反色和入场重播。重播入口移到顶部，方便手机预览时看到完整的入场构图。它展示视觉方向，不代表正式网页已完成改版。
