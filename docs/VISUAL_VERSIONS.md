1. 修改前读取本记录和 manifest，确认当前预览已存在对应快照，校验内容一致；如有尚未记录的版本，先补存，不能直接覆盖丢弃。
2. 在当前预览上修改并检查，完成后保存到下一个未使用编号，例如 `v006-<简短名称>.html`。快照采用新文件，不覆盖已有编号。
3. 更新 manifest 的当前版本、来源版本、说明和校验值，并同步本记录与 `VISUAL_DIRECTION.md`。
4. 恢复时将指定快照复制到当前会话允许写入的预览位置，再保存为新的交付编号，注明恢复自哪一版。被替换的版本和原快照都继续保留。
5. 最终回复告知本次版本编号，以便用户之后准确指定恢复目标。
