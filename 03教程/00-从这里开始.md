# 博客维护：从这里开始

更新：2026-11-09。适用：当前 Astro 博客与 GitHub Pages 工作流。

平时只记一条流程：**改源文件 → 本地检查 → 提交并推送 → 等部署成功 → 打开网页复查。**

## 你需要的四篇短教程

1. [发布或修改文章](01-发布或修改文章.md)：写正文、配图、放附件。
2. [预览与上传更新](02-预览与上传更新.md)：电脑操作和发布检查。
3. [维护与故障处理](03-维护与故障处理.md)：改资料、修错误、回退。
4. [让 skill 处理与在平板阅读](04-Skill交接与平板阅读.md)：可直接复制的任务描述。

上传阅读优先使用 `博客维护手册-平板阅读版.md`，它已经合并完整教程，不依赖本地相对链接。分篇与合并版只选一种上传，避免重复。

## 文件放哪里

- 文章：`src/content/posts/`，通常一个 `.md` 对应一篇文章。
- 图片：建议 `public/images/文章英文名/`。
- PDF、压缩包等附件：建议 `public/files/文章英文名/`。
- 新文章模板：`templates/post-template.md`。
- 本教程：`03教程/`。该目录不会自动成为网页文章。
- 网站生成结果：`dist/`。这是构建结果，不要直接改。
